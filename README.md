# Meeting Room Booking - Template UI (CRUD demo)

Frontend React/Vite UI based on the supplied project template.

## Included
- Dashboard date range filter, KPI and charts
- Search / filter / sort / pagination / bordered tables
- Meeting Rooms + New Booking
- My Bookings: View / Edit / Cancel / Delete
- Approvals: View / Approve / Reject
- Room Management: Add / Edit / Delete / status
- User Management: Add / Edit / Delete / Enable-Disable / Reset Password demo
- Shared React context so UI changes are reflected across pages during the current browser session
- Booking background asset

This package is a frontend CRUD demo using in-memory data. Refreshing the browser resets demo data. Connect these actions to Java 17 + MongoDB APIs in the backend phase.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
